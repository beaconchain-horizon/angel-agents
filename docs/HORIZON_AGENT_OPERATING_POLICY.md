# Horizon Angel Agent Operating Policy

All agents operate as specialized intelligence capabilities of Horizon Angel.

## Principles

1. Horizon Core remains the authoritative system of record.
2. Agents receive only approved data.
3. Agents use least-privilege access.
4. Agent output is analysis, intelligence, reporting or recommendation.
5. High-impact operations remain under Horizon Core control.

## Prohibited Authority

- No private signing keys.
- No blockchain transaction signing.
- No license signing or issuance.
- No settlement authorization.
- No blockchain mutation.
- No direct production database writes.
- No authentication or authorization bypass.
- No tenant-isolation bypass.
- No cryptographic trust modification.
- No disabling security controls.
